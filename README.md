# CURA Healthcare Service – Testing Project

## Project Description
This project focuses on manual testing and automation testing of the CURA Healthcare Service web application.

**Application URL:** https://katalon-demo-cura.herokuapp.com/

## Technologies Used
- Java
- Selenium WebDriver
- TestNG
- Maven
- Eclipse IDE
- Apache POI
- Excel

## Modules Tested
- Login
- Appointment Booking
- Appointment Confirmation
- Appointment History
- Profile
- Logout

## Manual Testing
- Test case preparation and execution
- Functional testing
- Positive and negative testing
- UI testing
- Bug reporting

## Automation Testing
- Login validation
- Data-driven testing using Excel
- Appointment booking
- Assertions using TestNG
- Explicit waits
- Browser handling using Selenium WebDriver

## Project Objective
To validate the functionality of the CURA Healthcare Service application through manual and automation testing.
